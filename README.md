# WEBSITE UMKM Kembang Cerita Flowers

## 📌 Deskripsi Proyek
Website UMKM merupakan proyek pengembangan sistem berbasis web yang dirancang untuk membantu digitalisasi pengelolaan dan penyajian informasi usaha mikro, kecil, dan menengah (UMKM).

Repository ini digunakan sebagai tempat penyimpanan source code, dokumentasi, rancangan sistem, serta file pendukung selama proses pengembangan proyek.

## 🎯 Tujuan Proyek
1. Mengembangkan website berbasis teknologi web dengan bekerja sama dengan UMKM
2. Menerapkan konsep basis data relasional.
3. Mengimplementasikan pengelolaan data melalui sistem informasi.
4. Mendokumentasikan proses pengembangan proyek secara terstruktur.

## 🛠️ Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Bootstrap

## 📂 Struktur Repository
- `source-code/` — Source code website.
- `database/` — File database SQL dan rancangan relasi database.
- `diagram/` — Use Case Diagram dan diagram perancangan sistem.
- `documentation/` — Dokumentasi proyek.
- `presentation/` — File presentasi proyek.

## 📑 Dokumentasi Proyek
Dokumentasi pendukung proyek akan disimpan dan diperbarui melalui repository ini, meliputi:
- Use Case Diagram
- Entity Relationship Diagram (ERD)
- Relasi Database
- Dokumentasi perancangan sistem
- Presentasi proyek
